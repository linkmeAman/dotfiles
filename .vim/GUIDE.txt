  LEADER KEY: <Space>
  TIP: Look at your bottom status bar for permanent hints!
       Press <Space> for the interactive Which-Key popup menu.

       Press <F1> or <Space> ? to open this guide anytime. Press 'q' to close.

==============================================================================
1. SUGGESTIONS, HINTS & COMMAND DISCOVERY (NEW!)
==============================================================================
  WHICH-KEY MENU (<Space>)
    --> Press <Space> to display the interactive key suggestions menu.
    --> Press <BS> (Backspace) to GO BACK to the previous menu level.
    --> Press <Esc>, <C-c>, or 'q' to CLOSE / DISMISS without executing anything.

  COMMAND PALETTE (<Space>p or <Space><Space>)
    --> Fuzzy search ANY Vim command, tool, or action.
    --> Press <Esc> or <C-c> to CLOSE / CANCEL immediately.

  POPUP MENU ON ':' COMMAND LINE (wildoptions=pum)
    --> When typing ':' commands, press <Tab> or Arrows to cycle suggestions.
    --> Press <C-e> to dismiss suggestions, or <Esc> to cancel.

  COPY & PASTE (MACOS SYSTEM CLIPBOARD)
    --> Highlighting text with mouse automatically copies to clipboard on release!
    --> Press <C-v> to paste from macOS clipboard in Normal, Insert, or Command mode.
    --> In Visual mode: 'y' or <C-c> copies directly to macOS clipboard.

  PERMANENT BOTTOM HINT BAR
    --> The bottom status bar shows: ⌨ <Space>:Menu  <Space>p:Commands  <F1>:Help

3. OPENING FOLDERS & PROJECT WORKSPACES
==============================================================================
  v .                      Open current directory (NERDTree opens automatically!)
  v path/to/project        Open any project folder directly
  <Space> e   or <C-n>     Toggle NERDTree file explorer
  <Space> e f              Reveal and highlight current file in NERDTree
  <Space> f   or <C-p>     Fuzzy search files across the entire project (fzf)
  <Space> g                Live text search with ripgrep across the project
  <Space> b                Switch between open buffers

6. MOTIONS & EDITING POWER TOOLS
==============================================================================
  s{char}{char}            Jump directly to any 2 characters on screen (Sneak)
  S{char}{char}            Jump backwards to any 2 characters on screen
  <C-d> / <C-u>            Smooth animated scrolling (Smoothie)
  gcc / gc (visual)        Toggle line / block comments (Commentary)
  ysiw" / cs"' / ds"       Surround motions (Surround)
  <C-n>                    Multi-cursor word selection (Visual Multi)
  <Space> u                Visual undo branch tree (Undotree)
  <Space> w / q            Save file / Quit

==============================================================================
7. WINDOWS & SPLITS
==============================================================================
  <Ctrl-h/j/k/l>           Move to left / down / up / right window
  <Space> v s / v v        Split horizontally / vertically
  <Space> v c              Close current window
  Shift-L or ]b            Next buffer
  Shift-H or [b            Previous buffer
  <Space> b d              Close current buffer

==============================================================================
8. TROUBLESHOOTING & GETTING UNSTUCK
==============================================================================
  Stuck in FZF / Rg search :  Press <Esc> or type :close<Enter> to dismiss
  Stuck in Terminal / AI   :  Press <Esc> to exit insert, then :close or <Space>vc
  Reset / Close all splits :  Type :only (<Space>vo) to keep only current file
  Force quit without save  :  Type :qa! (<Space>Q)
